
ATM-SIMULATION

ATM Simulation is a software program that copies the functions of a real ATM machine. It allows users to perform banking tasks like cash withdrawal, balance checking, deposits, and money transfers using a virtual system. It is mainly used for learning programming and banking operations.

🏦 Purpose

💳 Simulates a real ATM banking system.
🔐 Allows secure PIN-based login authentication.
💵 Performs deposit and withdrawal operations.
📜 Stores and displays transaction history.
🧠 Helps understand basic banking and programming concepts.
🎯 Objectives

🔑 To create a secure ATM login system using PIN verification.
💰 To allow users to deposit money into their account.
💸 To enable withdrawal functionality with balance checking.
📊 To display the current account balance.
📜 To maintain transaction history records.
⚡ To improve understanding of conditions, loops, and functions.
✨ Features

🔐 Secure PIN Authentication
💵 Deposit Money Feature
💸 Withdraw Money Feature
📊 Balance Checking System
📜 Transaction History Tracking
🖥️ Simple and User-Friendly Interface
⚡ Fast Banking Operations
